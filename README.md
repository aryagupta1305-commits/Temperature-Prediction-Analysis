# Temperature Prediction

A machine learning capstone project that builds a model to predict temperature from historical atmospheric/humidity data.

## Dataset

Historical weather readings, including humidity, used as input features for the prediction model.

## Approach

Implemented end-to-end in a Jupyter notebook:

1. Data loading and cleaning
2. Exploratory data analysis of atmospheric variables
3. Feature engineering
4. Model training and evaluation
5. Prediction and results interpretation

## Tools

Python, Jupyter Notebook, pandas, scikit-learn

## Files in this repo

- `Temperature_Prediction_Capstone.ipynb` — full notebook (renders directly on GitHub with all outputs visible)
- `humidity.csv` — dataset used for training/evaluation

## Note on the dataset

The humidity dataset is large (~28MB). If it originally came from a public source (e.g. Kaggle), consider linking to the original source in this README instead of re-uploading it, to keep the repo lightweight.
